## Overview

Second-year undergraduate project: a **MATLAB** toolbox to evaluate **OMR (optical mark recognition)** answer sheets.

**Repository:** [OMR-Sheet-Evaluation-using-Matlab](https://github.com/mhlimon/OMR-Sheet-Evaluation-using-Matlab)

## Approach

- Input: scanned or captured OMR sheet image  
- Image processing to detect marked options  
- Comparison against a key to score the sheet  
- GUI-oriented workflow for faster evaluation than fully manual checking  

## Skills

MATLAB · image processing · basic UI/tooling for academic use  

## Note

Prototype / academic tool—not a certified examination platform.
