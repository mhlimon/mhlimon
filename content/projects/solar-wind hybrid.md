## Overview

Undergraduate **power systems lab** team project: modelling and simulation of a **PV–wind hybrid** generation concept in **MATLAB/Simulink**, aimed at exploring grid-oriented renewable supply ideas.

**Repository:** [Solar-Wind-Hybrid-Power-plant-simulation-with-simulink-matlab](https://github.com/mhlimon/Solar-Wind-Hybrid-Power-plant-simulation-with-simulink-matlab)

## Scope

- Hybrid renewable generation concept (solar + wind)  
- Simulation-based study (not a commissioned plant design)  
- Team academic work—limitations are expected and noted in the repo description  

## Skills

MATLAB · Simulink · basic power-system modelling · teamwork

## Note

This is an educational simulation. It should not be read as a complete engineering design package for a real hybrid plant.
